01 / INSTALL

A small start.

Choose your platform. The installer uses a prebuilt binary, verifies its checksum, and installs it in your user directory.

v0.3.0 is being prepared. Use a source build until the first binary release.

Shell · binary installer

curl -fsSL https://orch.pandaailabs.com/install.sh | sh

macOS Apple Silicon and Intel · Linux x64 with glibc 2.35+. Linux sandboxed commands also require bubblewrap.

Read the Shell installer ↗

PowerShell · binary installer

irm https://orch.pandaailabs.com/install.ps1 | iex

Windows x64. Native shell commands require your approval. Use WSL for sandboxed commands; install with the Linux command inside WSL.

Read the PowerShell installer ↗

Binary installation becomes available when a public release is published. The scripts are available now for review.

Build from source

The checkout pins its Rust toolchain. Rust and Git are required.

git clone https://github.com/sizzlecar/orchestral.git
cd orchestral
cargo install --locked --path apps/orchestral-cli

Source builds follow the public main branch. See its README for the commands it supports.

02 / FIRST SESSION

Make the connection.

Open a terminal in your project. Choose a provider, then start a conversation.

CLOUD API

Bring your API key

For OpenAI, set a key and launch Orchestral. Keys stay in your environment.

macOS / Linux

export OPENAI_API_KEY="your-api-key"
orchestral

PowerShell

$env:OPENAI_API_KEY="your-api-key"
orchestral
LOCAL API · v0.3.0

Point to your server

Connect an OpenAI-compatible server. A single available model is selected automatically; with several models, choose one using --model.

orchestral --base-url http://127.0.0.1:8000/v1

Custom URLs default to no authentication. If your server requires a key, add --api-key-env YOUR_KEY_VARIABLE.

Check the connection without generating a response

orchestral --base-url http://127.0.0.1:8000/v1 doctor --check-connection

The local API shortcut and connection check are part of the v0.3.0 release in preparation. Your server and model must support tool calling to perform coding actions.
